# Lippe Optics Website

A professional website for a university startup project showcasing the Mosquito Laser Targeting System concept.

> **⚠️ DISCLAIMER**: Lippe Optics is a **fictional startup company** developed as a university project for educational purposes. This website is a demonstration of business planning and web development concepts. The products, services, and company information presented here are conceptual and not real commercial offerings.

## Project Overview

This website presents **Lippe Optics**, a theoretical defense technology startup specializing in precision laser targeting systems. The project includes:

- **Mosquito Laser Targeting System**: A conceptual product combining laser technology with sensor systems
- **Market Strategy**: Phased approach from pest control to defense applications
- **Technical Documentation**: Product specifications and architecture overview

## Website Structure

- **Home**: Project overview and key features
- **Project**: Technical specifications and product details
- **About**: Company mission and strategic approach
- **Contact**: Inquiry form and partnership information

## Running Locally

```bash
# Install Jekyll
gem install jekyll bundler

# Install dependencies
bundle install

# Run development server
bundle exec jekyll serve
```

Visit `http://localhost:4000` in your browser.

## Deployment to GitHub Pages

1. Push to GitHub: `git push origin main`
2. Enable Pages in repository settings (Deploy from branch: `main`, folder: `/`)
3. Site available at: `https://[username].github.io/LO-website-demo`

## Customization

- **Content**: Edit `.md` files (index.md, about.md, project.md, contact.md)
- **Styling**: Modify `assets/css/style.css`
- **Config**: Update `_config.yml` for site metadata

## Technology Stack

- Jekyll (static site generator)
- GitHub Pages (hosting)
- HTML5 + CSS3
- Responsive design
